# 小红书官方分享 SDK 调研

调研日期：2026-07-31

本文件只引用小红书官方公开资料。无法从官方公开页面确认的能力明确标注为“未能从官方公开资料确认”。

## 结论摘要

小红书确实提供“分享开放平台”，能力包括“一键分享”和“快速发布”。官方首页当前同时列出 iOS、Android、HarmonyOS 和 JavaScript 接入方向，因此不能简单理解为只支持 iOS/Android 原生 App。

但官方首页当前显示“暂停接入”。本项目也尚无平台分配的 AppKey、iOS Bundle ID 绑定或 Android 包名绑定。因此，当前 Next.js 网页不能直接把官方 SDK 当成已可用能力上线，现阶段继续使用标准 Web Share API 是更诚实、可运行的方案。

即使使用官方 SDK，也不能把“调用分享”描述为无需用户确认的自动发布。官方能力基于唤起小红书 App 内发布工具；用户仍需在小红书中检查并完成发布。

## 1. 分享开放平台是什么

小红书官方将其描述为基于客户端代码的分享 SDK，为第三方内容型和工具型应用提供将图文、视频内容分享到小红书的能力。

官方资料：

- [分享开放平台首页](https://agora.xiaohongshu.com/)
- [平台能力概览](https://agora.xiaohongshu.com/doc)

## 2. “一键分享”和“快速发布”

根据官方能力概览：

- 一键分享：第三方内容型和工具型应用可将图文和视频内容分享到小红书。
- 快速发布：使用小红书 App 内的发布工具识别内容类型，可挂载话题，并提供标题或话题推荐能力。

两者都应理解为“把内容交接到小红书发布流程”，不是第三方网页在后台替用户静默发布。

## 3. 支持的平台

官方首页目前列出：

- iOS
- Android
- HarmonyOS
- JavaScript

因此，官方分享能力并非只面向 iOS/Android。官方 FAQ 也明确提到部分网络资源问题“JS SDK 也适用”。

不过，以下事项未能从当前官方公开资料确认：

- JavaScript SDK 是否面向任意普通移动网页开放。
- JavaScript SDK 是否要求特定合作方、登记域名或签名。
- 当前“暂停接入”状态下是否接受新的 JavaScript 应用。

## 4. 接入身份和审核要求

官方 Android 文档确认：

- 需要与小红书商务沟通。
- 需要提供 Android 包名。
- 平台提供对应 AppKey。
- AppKey 与包名不匹配会鉴权失败。

官方 FAQ 确认 iOS AppKey 与 Bundle ID 需要匹配。HarmonyOS 文档要求通过“快速接入”登记企业和应用信息，通过平台审核后获得 AppKey。

| 项目 | 官方公开资料结论 |
|---|---|
| App ID / AppKey | 需要；官方 FAQ 说明两者是同一概念的不同历史表述 |
| iOS Bundle ID | 需要与 AppKey 匹配 |
| Android 包名 | 需要提供并与 AppKey 匹配 |
| Android 签名 | 未能从官方公开资料确认 |
| JavaScript 域名登记 | 未能从官方公开资料确认 |
| 平台审核 | HarmonyOS 文档明确要求；其他平台的完整审核流程未能从公开资料确认 |
| 当前是否开放新接入 | 首页显示“暂停接入”，不能假设当前可申请 |

参考：

- [Android SDK 接入指南](https://agora.xiaohongshu.com/doc/android)
- [HarmonyOS SDK 接入指南](https://agora.xiaohongshu.com/doc/harmony)
- [官方常见问题](https://agora.xiaohongshu.com/doc/qa)

## 5. 可传递的内容

Android 和 HarmonyOS 官方文档公开的能力如下：

| 内容 | 官方公开资料 |
|---|---|
| 多张图片 | 图文笔记要求 1–18 张 |
| 视频 | 支持 1 个视频 |
| 视频封面 | 可选 0–1 张 |
| 标题 | SDK 数据结构中为可选 |
| 正文 | SDK 数据结构中为可选 |
| 标签/话题 | 能力概览提到快速发布可挂载话题；通用参数未能从公开资料确认 |

重要限制：官方 FAQ 说明，通过分享 SDK 自动填充标题和文案目前受到限制，已接入和新接入方都受影响。因此即使接入官方 SDK，也必须保留剪贴板备份和用户手动检查。

## 6. 用户是否仍需确认发布

是。公开资料将能力描述为唤起小红书 App 的发布工具或快速发布笔记流程，且错误码中包含“用户取消发布”。本项目必须继续让用户在小红书中检查内容并最终点击发布。

不能把 SDK 调用成功、系统分享 resolve 或内容成功交接解释为用户已经发布成功。

## 7. 当前项目能否直接申请或接入

当前不能按“已具备接入条件”处理，原因是：

1. 官方首页显示“暂停接入”。
2. 项目没有平台分配的 AppKey。
3. 当前项目是 Next.js 网页，没有 iOS Bundle ID 或 Android 包名。
4. JavaScript SDK 的新应用资格、域名要求和审核流程未能从当前官方公开资料确认。

如果未来恢复接入，应先通过官方平台或商务渠道确认 JavaScript SDK 是否接受此业务形态，再决定继续网页接入还是建设原生 App。

## 8. 从当前网页升级到原生 App 的工作

可参考 [原生 App 升级预留方案](./native-app-upgrade-plan.md)。主要新增工作包括：

- iOS 和 Android 应用工程。
- Universal Links 与 Android App Links。
- AppKey、Bundle ID、包名与签名配置。
- 小红书平台申请和审核。
- 官方 SDK 封装、回调和错误码处理。
- 相册、文件、网络与隐私权限说明。
- App Store 和 Android 应用市场发布。
- iOS/Android 真机兼容性、图片顺序、资源失败和取消流程测试。

## 9. 对当前网页实现的建议

当前继续采用：

```text
准备有序图片
→ 复制完整文案
→ 调起系统 Web Share
→ 用户选择小红书
→ 用户检查并发布
```

同时保留保存图片、复制文案和手动步骤。不要加入未经官方确认的 `xiaohongshu://` 或 `xhsdiscover://` Scheme。
